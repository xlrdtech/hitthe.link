What these are. Mockups, not production proofs. The logo is composited onto the real blank photography from the catalog, so colour, drape and shadow are the actual garments.

Before anything gets printed. The current logo file is 1280 px wide, which is comfortable for left chest, beanie cuffs and mugs. A full 12-inch front print wants roughly 1800 px — a larger export of the artwork is worth having before a big front run.

Stitching. The stitched versions here are a visual treatment of the full-colour artwork. A real embroidery run needs the mark redrawn as separate colour stops so the D and the C hold their shape in thread.
