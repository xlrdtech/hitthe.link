# hitthe.link — open to search engines and AI agents, EXCEPT the private paths.

# ⛔ WHY THIS FILE IS SHAPED THIS WAY — a defect measured 2026-09-05 04:18.
# It previously had ONE shared private Disallow list under `User-agent: *`, plus a
# separate group per named bot containing only `Allow: /`. Per the robots.txt spec a
# crawler that finds a group matching its OWN name uses that group and IGNORES the
# `*` group completely. So GPTBot, ClaudeBot, PerplexityBot, CCBot, Bingbot and
# Google-Extended were each reading `Allow: /` and nothing else — the private list
# bound to none of them. It also carried TWO competing `User-agent: *` blocks.
# Verified with a real parser, not by reading: every one of those agents returned
# allowed=True for /lifenote/lifenote.json, 52.9 MB of qi's own life record.
#
# ⛔ AND THERE IS NO BARE `Allow: /` ANYWHERE. It is redundant (a path with no
# matching Disallow is already allowed) and its POSITION silently changes the
# verdict: Google resolves by longest-match, so Disallow wins, but a first-match
# parser lets `Allow: /` win and returns allowed=True for every private path.
# Measured 2026-09-05: with `Allow: /` present, 28 of 42 checks came back allowed
# when they should have been blocked. Do not add one back.
#
# THEREFORE: the private list is repeated IN FULL inside every group. Do not
# "de-duplicate" it — the repetition is what makes it apply. Adding a new named
# agent without its own copy of the list silently exempts that agent.
#
# ⚠️ robots.txt is a REQUEST, not enforcement. It stops compliant crawlers only.
# Anything that must actually be private needs auth, which GitHub Pages cannot do —
# that is the reason for the move to Cloudflare Workers (real headers, real gate).
#
# qi standing rule: no medical details, phone numbers, addresses, chat IDs or
# credentials on a public URL. qi 2026-09-05 04:17: "I'm not supposed to be on
# Google unless I say it's ready."
