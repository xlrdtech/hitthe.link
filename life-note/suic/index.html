Two facts are recorded: it is an IDE, and it is the place where two things that no existing editor understands get written — the .sel file format and the agent fleet itself. Everything past that is unspecified.

02The name

SUIC + IDE

Set as two tokens, because that is what it is: a four-letter product name followed by the standard abbreviation for an integrated development environment. Run together the letters spell another word, and the wordplay is deliberate — but the thing itself is an editor, and the wordmark is set split so it reads as one.

03Why a replacement, not a plugin

Reason one

A format nothing else parses

.sel is the Self Exec native proprietary format. No existing language server, linter or syntax definition knows it.

Reason two

Manifests that aren't manifests

automanifests is explicitly not package.json or manifest.json — so every tool that assumes those assumes wrong.

Reason three

Agents are the artifact

The fleet is authored here, not just code. An editor whose unit of work is a file rather than an agent is the wrong shape.
