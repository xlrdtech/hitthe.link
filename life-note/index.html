02The inversion

The original

Death Note

A book with one rule: write a name in it, and that life ends. The power is subtraction. Every use costs something irreversible.

The spinoff

Life Note

The same object, inverted. Written for developers, and life-affirming by design — the note is where something begins rather than ends.

The pairing is the idea. A developer's notebook is already where things get born; naming it against Death Note makes the direction explicit.
