1. Co-Browsing & Remote Control Platforms

These handle programmatic session sharing and touch-free remote interaction for your PWA

Hyperbeam
Role: Virtual cloud browser API.
Best For: Embedding a headless or multiplayer virtual Chromium browser directly into a PWA or web app via iframe/SDK. Allows users or automated agents to interact with third-party web apps without local browser extension limits.
Docs/API: Hyperbeam API Documentation
Surfly
Role: Universal, zero-install co-browsing platform.
Best For: Collaborative browsing, DOM transformation/masking, and full session control without requiring client downloads. Highly stable across web and mobile web contexts.
Omnifox
Role: Omnichannel communication platform with native co-browsing.
Best For: Launching live co-browse sessions directly from real-time chat widgets and messaging flows without installing software.
Cobrowse.io
Role: Developer-first co-browsing SDK.
Best For: Deep integration directly into custom web apps, PWAs, or native mobile apps (iOS/Android) with fine-grained element masking and reverse control.
TeamViewer Web Client
Role: Web-based remote desktop access.
Best For: Managing and controlling external host machines directly from a browser tab without needing a dedicated desktop client open.

Afina Browser
Role: Anti-detect, isolated multi-profile browser.
