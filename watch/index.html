Static vs dynamic

Queued shortest first. The 3-minute one had the best view-to-subscriber ratio of the three, which is the only quality signal available before watching.

Queue

Static — what you have

  • A finished file written once and stored
  • Everyone gets the identical thing
  • No code runs when someone opens it
  • Cannot know who is looking
  • Cannot show live numbers
  • Only changes when you reload

Dynamic — what you asked for

  • Code runs at the moment someone opens it
  • Built for that person, with their data
  • Holds an open connection — data pushes in
  • Inbox fills, numbers move, cursors appear
  • Changes while you watch, no reload
  • Cloudflare Workers + Durable Objects
The line that matters: static you refresh, live changes on its own. Every page on hitthe.link today is static — Cloudflare delivers them in milliseconds, but they are files. Fast delivery of a fixed page is still a fixed page.
