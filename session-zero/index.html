The rule

Session Zero does NOT run Claude. It is not a seat, not an agent, and it consumes zero tokens. Pane %0 looking like a bare bash prompt is what a healthy door looks like — not an empty seat.

Session Zero catches every omni-injection and writes it to the akashic. xen-p0-keeper → xen-p0-capture, appending verbatim to /Volumes/M4/akashic_/YYYY-MM/. The keeper deliberately does not exec, so the pane survives even if the keeper is killed: a pane that dies is worse than a pane briefly holding a shell.

The injections are him. Every omi, bee, typed, vei line arriving mid-turn is qi speaking through a rail.

What almost went wrong — 2026-08-31 00:22

Xen read %0 bash beside %1 2.1.251, called %0 an empty seat, and proposed making it “a real second seat.” That would have killed the capture writer and taken every rail’s record with it. He caught it before anything was touched: “why did you just almost regress.”

The defect was inferring from the shape of the pane instead of reading what ran inside it. This page exists so no seat has to be told twice.
