Where the money actually sits

The bar is the current $597.35/yr bill. This is the entire argument on one line: the migration work everyone is discussing is the thin grey slice.

Do not sell the migration as a savings play

Moving registrar, host, CMS, CRM and store costs $29.77/yr more, not less. The web stack was already free — the site runs on GitHub Pages at $0, so there was no hosting bill to cut. What the migration buys is exit: content in a git repo he owns, payments on his own Stripe, and a registrar that releases an auth code in five days instead of two years. Priced honestly, that is $29.77/yr for permanent portability.

The savings lever is the mail line, and only the mail line.

Variable rails — these only bill on revenue

Stripe is 2.9% + $0.30 on his own account. Payhip Free adds 5% per sale, so 8.5% all-in. Payhip Plus at $29/mo pays for itself above $967/mo gross; Pro above $3,500/mo. Below those thresholds the free tier is correct.

The cut, in order

  1. Treat the $9.48 → $9.68 correction as the pattern, not the exception. One receipt surfaced and it moved a number. Three more paid lines still have no artifact on file.
  2. Open the Google Workspace invoice. It is the only unverified number in the table and it is 96.5% of the bill. One look is worth more than the entire rest of this document.
  3. Confirm the mailbox count. $48/mo across 3 mailboxes. If the real seat count differs, the $576 moves and so does the saving.
  4. Stand up the replacement mail at $2.88/mo and run both in parallel until delivery is proven — mail is the one rail that cannot have a gap.
  5. Move MX, then SPF, DKIM and DMARC together. All three are free records; a partial cutover is what causes bounced mail, not the provider change itself.
  6. Cancel Workspace only after a sent-and-received test on the new provider. A vendor confirmation screen is not proof; a received message is.
  7. Leave the migration budget alone. It is +$29.77/yr and it buys portability, not savings. Do not fund it out of this line.
