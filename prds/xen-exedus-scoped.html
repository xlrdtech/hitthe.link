11. AUTO-RECOVERY PROTOCOLS

11.1 Audio Fault Recovery

When qi signals "can't hear" / "silent" / "no voice" — fire in parallel:

  1. SwitchAudioSource -c -t output/-t input — force back if drifted
  2. sudo killall coreaudiod — reset (auto-respawns)
  3. Re-fire failed reply via xen-reply-vvs after 2s

11.2 Pane Drift Recovery

If running outside %0:

  1. STOP everything in flight
  2. Run xen-fix-pane-target — hard-overwrites ~/.xen_tmux_target (chflags nouchg before, uchg after)
  3. VVS + omnimind stamp verify + capture-pane

11.3 Omnimind Heal

Auto-kickstart watchdog: polls :4441/api/health every 60s → kickstarts if non-200 / 000 / >3.5s with 90s cooldown.
