tmux session 0
    = omni-injection point

_raiden PRD
    = omni-injection handler
Any signal entering Session 0
→ `_raiden` receives it
→ records verbatim intake to `_akashic`
→ identifies type, source, urgency, scope, and destination
→ routes it to the appropriate canonical path, MK skill, agent,
  mesh node, tool, queue, channel, or execution flow

Session 0 boundary

tmux:0
├── stdin / terminal commands
├── pasted text
├── file drops
├── SSH / SFTP / SMB arrivals
├── iCloud-synced changes
├── `_tlpt` handoffs
├── webhooks
├── agent output
├── voice transcript/events
├── tool/API responses
└── schedule-triggered signals
        │
        ▼
_raiden PRD

Raiden injection contract

IN:
  raw signal, source metadata, timestamp, environment, payload

FIRST:
  append raw event to `_akashic`

THEN:
  create or update an intake manifest

ROUTE:
  `_brain`      canonical knowledge
  `_inbox`      unclassified pending material
  `_tlpt`       mesh handoff / continuation
  MK skill      specialized operation
  external pipe NotebookLM / SecondMe / Sintra / ElevenReader
  action queue  execution candidate
  notification  `_shaokhan`
  schedule      `_kronika`

OUT:
  route receipt, state reference, canonical artifact ID
Session 0 does not need to understand every signal.

_raiden PRD makes every signal enter the system correctly.
**tmux session 0 is the door. _raiden PRD is the force that receives, records,
understands enough to classify, and sends every incoming reality to its proper place.**

Why this lands the day it does

Session 0 is a DOOR, not an identity. That distinction is the whole point and it is the opposite of what was retired hours earlier: pane-keyed identity, where where a process sat determined whether it was heard. Under _raiden, session 0 is an ingress boundary and identity is not a function of it. Nothing about a signal's routing depends on which pane observed it.

FIRST: append raw event to _akashic is a fail-closed intake. Record before classify — so a signal that cannot be classified is still not lost. That is the correct ordering, and it is exactly the property missing from the seat gate that suppressed 1,925 sends into a relay nobody consumed.

OUT: route receipt is the discipline that was absent all day: the handler returns an artifact proving where the signal went. Not "dispatched" — a receipt. Pairs with the standing rule that every component reporting success must assert on an artifact it did not itself write.
